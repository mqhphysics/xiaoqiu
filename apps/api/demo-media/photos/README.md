# 校园照片展示样本

02、06 为官方资讯示例配图，03、04、05 为社区示例配图，均由用户于 2026-10-01 提供。照片的原始哈希与用途见仓库 `参考图片/03-校园足球实拍-2026-10-01/sources.json`。

01、07–16 是同一批已授权原片的派生裁切，只改变取景和横竖比例，供绿茵动态的错落图文和多图示例使用。01、10、11 来自 `01-campus-match.jpg`；08、12、16 来自 `03-team-lineup.jpg`；07、13、15 来自 `04-team-huddle.jpg`；09、14 来自 `05-team-celebration.jpg`。多图动态的封面仍是可直接读取的单张地址，其余张数由 `DEMO_PHOTO_ALBUMS` 展开。

可见年份为 2025 的照片不会写成 2026 年演示比赛记录。照片中的真实人物不与演示账户、球员资料或真实摄影者身份自动关联。WebP 压缩去除元数据；派生图只裁切构图，不改照片中的人物、文字或比赛事实。原件仍保留。

# TEAM-01 桌面 H5 主队与球队详情

分配依据：2026-10-03 用户提供三张参考图，要求完成主队页、球队详情弹窗及球队名称的轻微绿色悬停提示。上方选择条以第一张图为准；另外两张用于下方布局与详情窗口的球队介绍。

架构基线：[晓球产品与技术架构最终版](../architecture/晓球产品与技术架构最终版.md)。执行根目录 AGENTS.md。范围为桌面 H5，移动 H5 和微信沿用原有页面及业务行为；球队管理、名单提交与审核保留原入口。

本轮文件范围：

- 新增 `components/team-hub/`，共用三个内容选项、球队介绍、球队选择、球员关注及详情窗口。
- 新增主队和球队详情 `.h5.tsx` 页面入口，以及 `features/product/team-navigation` 平台模块。
- `app.tsx` 挂载平台详情宿主；`product-ui` 接入球队名与队徽点击；`overlay-focus` 支持弹窗嵌套。
- 现有首页、赛程、数据、我的、球员、比赛、球队目录和赛事详情仅修改直接关联的球队入口。
- `product.repository` 为既有公开读取增加可选赛事参数；发布组件透传可选球队 ID。
- 本卡与验收记录。

验收：

1. 默认展示已保存主队，顶部可查看关注球队及球员；球队名称/队徽打开详情，小圆按钮切换下方内容。
2. 主队切换为标题旁的小图标，悬停显示提示；弹窗默认列出当前赛事全部球队，支持搜索和真实 API 保存。
3. 三项为动态与赛程、球员与数据、资料与转会；主队页与详情复用内容。
4. 球队动态、比赛、阵容及统计读取既有 API；缺失的历史故事、荣誉、转会与技术统计明确为空，不填入参考图示例数字。
5. 桌面球队入口打开详情弹窗，保留原页面 URL；弹窗有基础资料、键盘关闭、焦点恢复及嵌套窗口处理。
6. 适当检查后在 `codex/h5-team-dashboard` 本地提交，推送、合并及部署另行安排。

结果与全部文件清单见 [验收记录](../testing/H5-主队与球队详情-2026-10-03.md)。

# NAV-03：04与15主队图案双版本对比

依据：[架构基线](../architecture/晓球产品与技术架构最终版.md)、[AGENTS](../../AGENTS.md)。用户选择网络参考04和15，要求分别试做：图案与队徽搭配但更浅，未选中时显示简化骨架，选中后从骨架生长成完整图案；本轮只用曼联和曼城对比，直接打开网站，不制作视频。

## 修改文件与实现

- `apps/mini-program/src/components/public-shell/team-nav-designs.h5.ts`：04的菱形、交叉长弧、大回环，以及15的卷草、内卷、叶脉细纹；提供短弧骨架和逐段生长时序。
- `team-nav-focus.h5.tsx`：按版本渲染SVG，未选中仅显示两段骨架；完整图案没有提前显示成浅色轮廓。试样模式展示既有曼联/曼城队徽。
- `navigation-transition.h5.ts`：按真实SVG骨架/完整路径长度比例开始绘制，衔接已有短弧；分层长出回环和细纹，退选收线，重播保留骨架。04总长1310ms，15总长1550ms。
- `team-nav-focus.h5.scss`：浅色图案、底纹、细纹层级及验收控件；保持导航布局，保留减少动画与移动H5边界。
- `team-nav-palette.h5.ts`：新增比队徽主辅色更浅的装饰配色，保留此前配色识别规则，不扩展球队配色样本。
- `team-nav-palette.h5.test.mjs`：增加曼联/曼城装饰色更浅的测试。
- `team-nav-preview.h5.tsx`：仅在本机3101且带版本参数时显示对比控件；切换两版、两个队徽试样、重播。控件不修改账号主队；普通入口没有试样控件或试样队徽。

参考：[04菱形与回环](https://www.vectorstock.com/royalty-free-vectors/diamond-divider-vectors)、[15 Monroe Scroll](https://www.shulerstudio.com/products/monroe-scroll-print)。已读取原图核对轮廓；本轮重新绘制适合导航尺寸的SVG，参考原图只保存在被忽略的本机目录，不随源码提交。

## 命令与结果

- `node node_modules/typescript/bin/tsc -p apps/mini-program/tsconfig.json --noEmit`：通过。
- ESLint定向检查上述TS/TSX与配色测试：通过。
- Prettier定向检查：通过。
- `node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --experimental-strip-types --test apps/mini-program/src/components/public-shell/team-nav-palette.h5.test.mjs`：7/7通过。
- `npm --prefix apps/mini-program run build:h5`：通过；保留资源及入口体积警告。验收构建使用3101 API地址及本机短密码选项，配置文件没有修改。
- `git diff --check`：通过。
- 浏览器：04未选中只有2段骨架、6条完整路径隐藏；15未选中只有2段骨架、16条完整路径隐藏。骨架是完整路径的相同前缀，动画从已绘制骨架长度继续，绘制进度递进到完整。两版及两种队徽可直接切换，无页面异常。
- 721、768、960、1040、1280、1440px：图案不覆盖相邻导航图标；键盘、减少动画、390px原底部导航通过；无参数时对比控件和试样队徽均不存在。

# V2-02 名单与队长阵容

分支 `codex/v2-roster-workflow`，独立聊天“完善队长阵容编排功能”。用户明确增加 H5 战术、自定义站位、拖拽首发/替补交互，不只后端名单。

独占 apps/api/src/roster（含旧读取controller与PG测试迁移到真实登录）、features/captain-roster、my-team功能入口；不重做共享导航/首页/登录、不改微信行为。后端复用auth正式helper，独占TeamLineupPlan/Revision的业务服务和DTO，但共享schema/migration由Integrator生成。

要求：名单SAVE/SUBMIT/RETURN/APPROVE/LOCK/REOPEN；锁定先建未锁快照/entries再lockedAt；同赛事同球员跨队竞争只一方锁定；资格/期限/人数来自规程，改规程需重新确认；幂等、审计、站内通知在事务内。

队长云端战术/单场阵容按[公共契约](../architecture/V2-工作流公共契约.md)接真实读取/保存/版本历史，5/7/8/11人制、点击补充拖拽、交换/取消/撤销、本机草稿与服务器保存分清。历史payload保存当时全部name/kind/绑定上下文，不借当前头记录复原。真正POST成功才新增版本，断网保持原键重试；MATCH_LINEUP与锁定名单绑定。

真实PG覆盖多角色闭环/旧快照/并发/云端重放和通知；浏览器使用真实API验证排阵/命名保存/刷新回读，不拦截冒充。原型/仅本机保存不能交作云端完成。仅commit自己任务文件，不Push。

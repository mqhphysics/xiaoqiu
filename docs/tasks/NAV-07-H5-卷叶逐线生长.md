# NAV-07：单色卷叶线稿，逐根生长

依据：[架构基线](../architecture/晓球产品与技术架构最终版.md)、[AGENTS](../../AGENTS.md)。用户明确要求每根线条实际长出；取消原图遮罩展现，保持单色，按参考卷草/叶子的结构细化，外侧略上翘包围队徽，重点补足中间两个内卷的叶心纹理。

## 修改文件与实现

- `apps/mini-program/src/components/public-shell/team-nav-leaf-lines.h5.ts`：依据参考结构重建为可编辑的Bezier中心线；外侧卷草抬起，内侧叶心独立放大并移到队徽两侧。另重画双层支撑茎、叶心回卷边缘和内层褶线。每侧327条路径，包含49条内卷细节路径；采用不同线宽形成卷边、叶缘及细纹的层级。
- `team-nav-focus.h5.tsx`：实际渲染654条独立SVG路径，所有路径`pathLength=1`，未选中仅保留2段短弧骨架。没有SVG image、位图或整幅图案的遮罩揭示。
- `navigation-transition.h5.ts`：每条路径单独使用`strokeDashoffset`控制已绘制长度；从支撑茎到叶心、卷边和褶线依次长出，总长约1.5秒。按当前每条线的实际进度衔接快速切换、收线及重播。
- `team-nav-focus.h5.scss`：保留单一金色`#c5aa6d`，移除图片遮罩和裁剪样式，保持416px导航与168px纹样的紧凑宽度。
- `team-nav-preview.h5.tsx`：说明改为“单色线绘卷草”；四个队徽和重播继续使用。
- 本任务卡记录结果；NAV-06及历史素材README提示已切换实现。

线稿重建包含参考图的中心线、曲率平顺及结构调整；不是把自动提取数据声称为完全原创手绘。现有参考素材及其派生图形的来源许可仍待确认，本轮仅做本机设计验收。

# FEED-03 评论同步转发到动态

2026-10-08 用户明确要求：保留直接转发，在桌面评论框表情右侧增加圆点勾选项“评论同步转发到动态”；勾选后发布评论并自动生成引用原帖的动态，不附带标签，完成后直接集成 main。

范围：post-overlay、post-social 桌面样式、product Repository/响应类型，以及现有评论 DTO/Service 和对应验收。使用已存在的 Post 引用字段与幂等键，不改模型、迁移、公共契约、依赖或微信界面。评论与转发须在同一事务内提交/回滚，重试不得生成重复评论或动态。

结果见[验收记录](../testing/H5-评论同步转发-2026-10-08.md)。

# TEAM-05 标签输入与单行推荐

2026-10-03 用户要求简化发布标签：直接输入后回车添加，下方只保留一行 3～4 个“#标签”，去掉类型／院系等说明，按实际使用频率优先推荐。

范围：桌面 H5 标签选择器及现有建议查询排序，延续本聊天 main 集成授权。使用当前组织、赛事的已发布帖子统计真实标签次数；没有记录时默认话题补齐。不修改模型、迁移、公共契约、依赖、微信或移动界面。

验收：输入回车、点选、去重、删除及关联 ID 保留；中文组字回车不提前添加；推荐最多 4 个且保持单行、无滚动框；所有类型按发布次数统一排序，隐藏／其他组织／其他赛事的帖子不计入；同名实体仍要求明确选择。

结果见 [验收记录](../testing/H5-简洁标签与频率推荐-2026-10-03.md)。

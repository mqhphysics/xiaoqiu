# MATCH-03：详情内编辑与首次发布

用户本轮要求：删除无用小字，编辑按钮居中且仅限本场编辑员；删除旧 H5 编辑界面，比赛详情内编辑比分、两队红黄牌/换人数量，自动生成对应事件并按填写时间排序，底部“完成编辑”。完成记录改为“申请修改”。

用户随后明确：允许同时编辑；第一个通过校验的完成版本直接公开；较晚完成的版本留存系统，不自动覆盖先发布的结果。此指令取代本轮起初考虑的“提交后管理员审核”及编辑互斥方案。发布后的修改仍需申请并由管理员开启更正。

编辑员指有效且在本场 MATCH/TOURNAMENT 范围内的 `MATCH_REPORTER`；仅有管理员身份不会出现详情编辑按钮。开始编辑留真实凭据记录，较晚完成只保存已开始的有效编辑会话，不能通过伪造旧版本覆盖正式结果。未完成可保存草稿；完成校验分钟、名单、配对换人、比分与进球一致。

# FEED-01 桌面 H5 动态详情与发布

分配依据：2026-10-02 用户要求参考左右分栏弹窗，完成动态详情、楼层回复、多图切换、滚轮缩放，以及发布框、内置足球和黄豆表情、多图预览、删除与 GIF。

架构基线：[晓球产品与技术架构最终版](../architecture/晓球产品与技术架构最终版.md)。遵循根目录 AGENTS.md；本轮只实现桌面 H5 的新交互，保留移动 H5 和微信原有行为。

本轮写入范围：

- 新增桌面动态组件：post-overlay、post-composer、post-social；本地表情、工具栏图标与许可证。
- features/product 的动态类型、兼容发布参数、平台导航和互动计数同步。
- app.tsx、product-ui/index.tsx、首页 index.tsx 中与本任务直接相关的挂载和接线；这些文件中其他任务的修改按行保留且不纳入本提交。
- API 的 experience DTO/Service、media Service、JSON 请求体大小设置，以及图片相关测试。
- 本任务卡与验收报告。

不改 Prisma schema、packages/contracts、生成 Client、依赖和锁文件。多图使用现有本地媒体适配器：保持 imageUrl 为可显示的封面，通过内容寻址相册文件名关联最多九张图片；响应增加兼容的 imageUrls。老图片和单图提交继续可用。

验收：

1. 桌面打开动态时 URL、原页面滚动位置保留；图片和评论左右分栏，评论独立滚动。
2. 评论按顶层楼层组织，支持回复及回复的回复；内容写入真实 API，点赞和评论数量同步到卡片。
3. 多图按上传顺序切换，悬停显示箭头，滚轮和按钮缩放，放大后可以拖动，提供缩略图与重置。
4. 发布使用无嵌套边框的输入区、表情/图片图标、最多九张缩略图、角标删除与 GIF 标记。
5. GIF 经过服务器处理仍保留帧、间隔和循环；发布重试幂等，隐藏动态禁止读取整组媒体。
6. 完成类型检查、相关测试、Lint、H5 构建及真实浏览器往返；本地 commit，推送/合并/部署另行安排。

结果见 [H5 动态验收报告](../testing/H5-动态弹窗与多图发布-2026-10-02.md)。

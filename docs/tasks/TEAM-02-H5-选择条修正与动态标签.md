# TEAM-02 桌面 H5 选择条修正与动态标签

2026-10-03 用户反馈：切换主队显示两个提示；去掉球队卡右侧的箭头和主队小勾；鼠标在横向关注列表中滚动时浏览后面的球队/球员，列表旁才向下滚动页面。新增发布标签：常用点选、输入后回车创建多个标签、右上角小叉删除，并在关联球队/球员的动态中展示。

用户在本聊天明确回复「授权本轮修改模型和迁移」，因此本轮可修改 `prisma/schema.prisma` 并新增标签迁移。其他公共文件所有权继续遵守 AGENTS.md，不改依赖、锁文件、contracts 或生成 API Client。

本轮基于 `codex/h5-team-dashboard` 的 TEAM-01 成果，范围为桌面 H5、直接相关的发布/公开查询 API、标签持久化和验证。移动 H5、微信及独立 Worker 不扩展修改。

验收：

1. 只保留深绿色自定义提示，删除原生 title 提示。
2. 球队卡没有箭头/小勾；卡片空白处选择下方内容，名称和队徽保留详情入口。
3. 关注列表有横向溢出时，滚轮横向移动；到列表末端也不带动页面下滚，列表旁保持正常页面滚动。
4. 标签支持球队、球员和自定义话题，常用点选、连续回车、去重和单独删除；中文组字回车不提前创建标签。
5. 球队/球员标签使用稳定 ID，名称由服务器确认；关联帖在两处列表持久显示。移除默认关联标签后不错误插入原列表。
6. 持久化遵守组织隔离、既有权限、幂等与审计规则；标签不能冒充球队官方发帖身份。
7. 适当检查后本地 commit；主目录合入、日常库迁移、推送或部署由集成负责人按另行授权安排。

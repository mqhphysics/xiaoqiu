# V2-01 认证与赛事上下文

分支 `codex/v2-auth-context`，独立聊天“完善晓球真实使用准备”。

独占 auth、公共 request-context/public-tournament helper、schedule、experience.controller/dto/service 的上下文/可见性块，及 app.setup CORS/cache增量。不写 roster/results/worker，不整页改前端。共享schema和根依赖由Integrator管理。

必要增量授权：旧管理站只发送开发头，会因新权限而失去真实工作台访问。本支可独占 `apps/admin-web` 的登录/session 门、工作台会话上下文和两个repository的Bearer接线及对应测试；保持既有视觉，不重做首页/登录艺术层、微信或公共H5壳层。不用Mock掩盖后台未登录/未配置API。

公开并导出 AuthService、AuthenticatedSession、AccessPolicyService 与 AuthorizeInApplicationService；新业务服务先 fresh session 再对象策略。管理员大小写/尾slash/未知路由不可越权，开发头不提权；公开资料只来自已发布赛事、批准报名与锁定名单。赛事/匹配状态保护不能把已赛比赛重排为未赛；共享模型落地后再保护有 confirmedReportVersion 的比赛。

接共同基线和[公共契约](../architecture/V2-工作流公共契约.md)，完成真实HTTP权限/公开边界/事务回归，提交自己的文件。当前交付 e7d27105 是待Integrator复核切片；旧名单开发头测试由roster改，反馈并发问题由Integrator定向修，不能因此回退正式权限。

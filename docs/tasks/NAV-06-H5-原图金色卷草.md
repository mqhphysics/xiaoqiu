# NAV-06：直接采用15原图，统一金色

> 本卡记录原图揭示版。用户随后明确要求逐根线条生长，当前实现已改为可编辑矢量线绘，见 [NAV-07](NAV-07-H5-卷叶逐线生长.md)。

依据：[架构基线](../architecture/晓球产品与技术架构最终版.md)、[AGENTS](../../AGENTS.md)。用户指出手绘与15参考原图仍差距明显，要求单色金黄色，明确允许直接使用原图；补充截图对比了旧重画与原图。

## 修改文件与实现

- `apps/mini-program/src/assets/nav-ornament/monroe-scroll-reference.svg`：嵌入原PNG全部字节，SVG视窗只去掉透明留白，不修改原纹样、羽纹或卷边。素材原图1000×1000，实际图案透明边界`99,424–901,576`，视窗`98 423 804 154`。
- 同目录`README.md`：记录来源、使用方式及许可未核实边界。
- `team-nav-focus.h5.tsx`：以原图遮罩展示，移除运行时自绘卷草、叶面、刻线与多色渐变；只渲染中央简化片段及左右完整纹样。
- `team-nav-focus.h5.scss`：统一原图金色`#c5aa6d`，原始长宽比804:154，常规宽168px、高约32.2px。纹样位于队徽下方，选中队徽上移4px以减少对内卷遮挡；五项导航仍宽416px。四个队徽试样当前均用同一金色。
- `navigation-transition.h5.ts`：从已有中央片段向两侧逐渐展开原图，约1.36秒完成；快速切换可接续当前裁剪进度并收回。没有缩放整幅图案或声称逐根重绘位图纹理。
- `team-nav-preview.h5.tsx`：试样说明改为“原图金色卷草”，保留四队徽与重播。
- 本任务卡记录结果，NAV-05加历史状态提示。

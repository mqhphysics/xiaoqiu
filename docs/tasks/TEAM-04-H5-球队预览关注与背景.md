# TEAM-04 球队预览关注与统一背景

2026-10-03 用户继续调整已集成的球队界面：预览卡右上角加入关注状态按钮，移除底部“查看完整球队资料”并减小高度；预览与详情顶部共用球队背景，现阶段允许统一样式。

范围：桌面 H5 球队预览与共享详情组件，复用既有真实关注接口和偏好更新事件。延续 TEAM-03 的 main 集成授权，保留 main 新增的导航装饰及独立 Worker。不增加数据库模型、API 契约、微信行为或团队自助上传功能。

验收：

1. 预览右上角可关注／取消关注，已关注状态、主队默认关注、加载／保存和错误状态正确。
2. 关注按钮不会打开详情；关注状态与主队栏及详情按钮同步。
3. 删除预览底部资料入口，队名和队徽仍可点击打开详情，卡片更紧凑。
4. 预览与详情顶部复用统一校园足球装饰背景，文字清晰可读。
5. 真实接口写入验收使用隔离数据库；日常入口仅进行只读验收。

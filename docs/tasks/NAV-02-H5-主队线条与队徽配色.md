# NAV-02：桌面主队线条生长与队徽配色

依据：[架构基线](../architecture/晓球产品与技术架构最终版.md)、[AGENTS](../../AGENTS.md)。用户本轮要求扩大主队装饰，放慢动画，适配主队配色；后续明确用从中心菱形共同起点长出的曲线替代花瓣，并直接打开完整网站验收，不制作视频。

## 实现与文件范围

- `apps/mini-program/src/components/public-shell/team-nav-focus.h5.tsx`：四对曲线，起点统一为 SVG 的 `(100, 71)`，取消填充弧面。每条曲线具有低透明度底纹和逐段绘制的彩色线条。
- `team-nav-focus.h5.scss`：桌面装饰画布198px，窄桌面约157px；深浅状态、圆润线端、选中队徽强调和减少动画处理。
- `navigation-transition.h5.ts`：菱形先亮，曲线错峰向外绘制，总时长1060ms；退选420ms反向收线。切换时捕获绘制进度，再次点击主队可重播。
- `team-nav-palette.h5.ts`：适配现有16个演示队徽；自定义队徽使用球队声明的主辅色；无主队回到默认绿金，非法颜色安全回退。
- `team-nav-palette.h5.test.mjs`：6项配色规则测试。
- `index.tsx`：向装饰组件传入现有主队，未修改导航业务。
- `team-nav-focus.tsx`：仅补充参数类型，非H5仍返回null。没有修改微信端行为或移动端布局。

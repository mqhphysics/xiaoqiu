## 已满足的验收

| 验收                         | 当前证明                                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 开发角色头不能提权           | 无会话 401；学生伪造角色/用户头仍 403；赛程和旧名单管理入口均经真实 HTTP 验证                                                        |
| 管理员按组织/赛事范围        | 赛事工作台过滤获授权赛事；不能创建组织级资料、操作他赛事或跨组织对象                                                                 |
| 队长与信息员对象范围         | 真实会话和数据库策略：队长仅本队；信息员明确 MATCH 或 TOURNAMENT scope；其他球队/赛事拒绝                                            |
| 撤销和过期立即生效           | 撤角色、停用成员、冻结用户、停用组织、会话过期和退出后拒绝；同 token 的身份读取反映最新角色                                          |
| 大小写、尾斜杠和未知管理路由 | 使用匹配路由模板；学生变体 URL 仍拒绝；未配置授权的 handler 对管理员也拒绝；显式服务授权交接仍由对象策略校验                         |
| 真实赛事进入后端五入口数据   | 不依赖 DEMO 编号；首页、赛程、数据、主队可选球队与本人资料完成实际 HTTP 读取；显式历史赛事选择和部署默认被验证                       |
| 公开搜索与信息边界           | 精确断言所选赛事锁定球员、已批准球队、非草案比赛的 ID；待审/未锁定/其他赛事资料排除；读取响应不含虚构完整学号和绑定邮箱              |
| 公开详情                     | 未发布赛事两种比赛详情都拒绝；待审球队拒绝；球员读取最近锁定版本                                                                     |
| 赛程旧结果保护               | LIVE、FINISHED、已有比分、已发布修订不能重新草案化；旧草案发布不能覆盖终态/比分；拒绝后原状态、比分和引用保留                        |
| 并发与事务                   | 两次草案分配只预留一次；两次发布只提交一个修订、真实操作者审计及一个 Outbox 事件；真实 PostgreSQL 故障注入证明整体回滚及后续重试成功 |

权限 helper 的签名与新模块接线要求见 [auth README](../../apps/api/src/auth/README.md)。队长、信息员的测试入口只存在于专属测试中，不冒充新名单/比赛报告业务 API。

## 集成与未验证边界

- 独立评论沿用现有一场一用户一条记录；评论可补充/编辑。未评分记录用 0 表示，均分、人数和分布只计算 1–5；数据库要求 0 分记录必须有非空正文。
- 新迁移仅调整 CHECK 约束，不改表、字段、Prisma 模型或已有评分。后台按组织范围锁定比赛行，使并发首次评分串行；不同分数再次提交返回 409。
- **集成时须同时纳入 H5、API 与新迁移，并在目标库执行迁移后重启后台。** 本轮没有把变化应用到日常 3000/3001。只换前端不能完成独立评论和不可改分。
- 没有修改 `packages/contracts/`、生成的 API Client、公共依赖、锁文件或 `prisma/schema.prisma`；公开读取响应新增可选 `ratingDistribution`，原接口路径保持不变。公共文件变更建议：无额外建议；新约束迁移需集成负责人一起安排。

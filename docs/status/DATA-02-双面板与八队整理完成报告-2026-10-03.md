## 已满足的页面要求

- 两个入口：球队排名、球员数据。
- 球队排名左小组赛、右淘汰赛，同时可见。默认左侧完整表格、右侧队徽简图；悬停右侧仅改变背景与边框，点击后右侧展开、左侧显示球队积分摘要。也可点击左侧切回。
- 小组前两名在完整表格和摘要中均标绿。标记文字为“小组前两名”，没有将演示签位描述为已确认的真实晋级资格。
- 淘汰树按照参考图：上方两场八强赛与第一场半决赛，下方两场八强赛与第二场半决赛，决赛居中；使用晓球绿白配色、简单连接线、败方淡化。三四名赛保留独立入口，不挤入冠军主线。
- 收起时隐藏队名；展开时显示队徽、名称和比分。待定席位显示中性盾形，不猜测尚未结束比赛的胜者。点球与进行中胜负不会误标为已淘汰。
- 球员数据左右并列射手榜、助攻榜，显示 API 返回的完整榜单（当前各前 10 名）。沿用现有球员资料弹窗及球队链接。
- 鼠标切换使用短过渡；键盘切换立即生效，减弱动态效果偏好关闭过渡。1024px 以下继续委派原数据页，没有附带重做移动或微信界面。

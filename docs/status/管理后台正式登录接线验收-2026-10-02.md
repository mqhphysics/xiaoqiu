# 管理后台正式登录接线增量

2026-10-02，分支 `codex/v2-auth-context`，基于已提交的 `e7d27105c9b43c75f628518f132b80210bcb7698`。本轮由用户授权的 Integrator 3 补充分配：只接必要的 AdminWeb 登录、会话、后台上下文和两个 Repository，保留原布局与功能，不改 H5 首页/登录、微信或公共依赖。

## 已实现及验收

| 项目           | 最终行为与证明                                                                                                                |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 登录入口       | 管理服务有配置才显示登录；组织编号来自部署配置或管理员输入，无固定开发身份；登录和 `/auth/me` 均是真实 API                    |
| 非管理员       | 普通用户即使密码登录成功也不能进入工作台，会清除本机身份并尝试撤销该会话；真实浏览器拒绝通过                                  |
| 真实身份上下文 | 工作台使用会话中的组织、用户和当前角色；API 请求只发送 Bearer 和正式组织头，不发送开发角色/用户头                             |
| 角色与对象范围 | 保留后端范围判断；赛事管理员只看到授权赛事，组织级按钮禁用；撤销角色后重新验证，工作台关闭                                    |
| 会话最小化     | sessionStorage 只保存 token、expiresAt；本人完整学号、邮箱和角色资料不持久化。重载后必须重新读取身份；存储损坏/失效拒绝       |
| 迟到响应       | 旧 401 和延迟 JSON 不能清除/覆盖新登录；身份验证结果及退出完成也按 token/当前修订核对                                         |
| 当前 401       | 服务端真实过期后，读取返回 401，客户端清除会话并回到登录；真实浏览器通过                                                      |
| 退出与失败重试 | 先移除本机凭据，再撤销服务端；失败显示撤销未确认并提供重试。真实断网后旧 token 仍有效，重试才将其撤销；后来另一管理员保持登录 |
| 请求时限       | 15 秒截止时间包含响应正文读取，验证取消和超时区分；受控时序测试覆盖未完成的 body                                              |
| 缺少 API       | 明确显示后台不可用，不进入工作台、不创建 Mock Repository、不读浏览器旧 Mock 数据                                              |
| 原功能         | 原赛事、球队、名单、赛程布局和操作保留；浏览器创建赛季后真实数据库新增一条，名单由真实已授权报名读取                          |

前端角色判断只改善入口与按钮体验，权限仍由服务端真实会话和对象策略执行。没有实现自动续期、设备列表、正式恢复、主题修改或新的比赛报告/名单审核 UI。

用户指出上轮队徽/队名错位，要求比分下增加简短日期，替换待定球队图标。本轮在 `codex/h5-data-interaction` 工作树继续修正，基线 `ee028c7`。没有改数据库、API、共享球队组件、主目录或微信。

## 问题与修正

错位来自旧 `.tree-team > span` 样式：共享 TeamCrest 的交互外层也是 span，被撑满队伍列后，内部块状图片留在左侧；队名按列居中。上一轮只验证溢出和交互，没有测量图形与文字的中心位置，遗漏了这个可见问题。

| Before                                              | After                                                          | Why                                           |
| --------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------- |
| 原图已知球队队徽与可见文字中心偏差 65.203–116.313px | 队徽与队名分开容器，各自居中；四个桌面宽度最大误差 0.0078125px | 避免把共享交互外层误当作图形本身              |
| 比分下没有比赛日期                                  | 展开显示 `09/01 10:00`，收起显示 `09/01`                       | 简短显示具体日期/时间，不放年份、星期等长文字 |
| 大轮廓盾形加号占位                                  | 浅灰绿双圈问号徽章，与已知队徽共用尺寸和中心                   | 明确待定，避免加号像新增按钮                  |

日期读取真实 `scheduledStartAt`，以校园 UTC+8 时区格式化；空值/非法值显示“时间待定”，不填造日期。保留必要的进行中/延期/取消状态。球队名称和队徽来源均来自同一个 API 球队对象；已知球队徽章仍沿用已有演示素材，不宣称为真实校园球队官方队徽。

# P0-REVIEW-01 基线只读审查

## 状态

Ready

## 工作方式

只读，不创建分支，不修改任何文件。

## 目标

独立检查 P0 基线和第 1 轮任务边界，尽早发现会导致并行返工、数据泄露或无法集成的问题。

## 审查范围

1. 对照 `docs/implementation/晓球方案A详细实施方案v0.2.md` 检查当前工程骨架。
2. 检查 `AGENTS.md` 与本轮三张开发任务卡是否存在写入范围重叠或遗漏。
3. 检查：
   - Monorepo 脚本与包依赖关系
   - TypeScript、ESLint、构建边界
   - 环境变量与密钥风险
   - Git 忽略规则
   - API、数据库、Outbox、Taro Spike 和 CI 的集成风险
4. 识别哪些验收项目前只是占位，不能误报为已完成。

## 输出格式

按严重程度输出发现：

```text
[P0/P1/P2/P3] 标题
证据：文件和行号
影响：
建议：
```

最后列出：

- 可以立即开工的任务
- 开工前必须修正的问题
- 集成负责人需要决定的问题
- 当前缺失的自动化测试

若没有阻塞问题，明确写出“未发现阻塞并行开发的问题”，但仍需说明残余风险。

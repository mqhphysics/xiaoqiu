# P2-REVIEW-01 真实名单与公开网站纵向切片复审

## 目标

只读审查第 3 轮三个开发分支及集成结果。不得修改文件、不得合并分支。

## 必查

1. 真实个人数据、DOCX、完整路径、Token 或生成产物是否进入 Git。
2. 姓名是否被错误用作唯一匹配依据。
3. 组织/赛事隔离、名单不可变快照、重复导入幂等和事务回滚。
4. 公开 API 是否只返回已发布赛事、已批准报名和最新锁定快照。
5. 公开响应、日志、AuditLog 是否泄露学号、手机号或导入路径。
6. H5 API 失败是否显式，不得静默回 Mock。
7. Admin adapter 是否与真实 API 一致，是否只展示脱敏字段。
8. Desktop 1440px、Mobile 390px、微信构建是否通过且主流程无明显布局问题。
9. Prisma migration、OpenAPI、类型检查、测试、构建和真实 PostgreSQL 集成测试。

## 输出

按 P0/P1/P2 严重级别列问题、证据文件和行号、影响、建议、三个分支判定、可否集成及推荐合并顺序。

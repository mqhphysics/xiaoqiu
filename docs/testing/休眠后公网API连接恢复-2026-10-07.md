- 原 3301 API、Worker 和 PostgreSQL 仍运行；API live/ready 均 HTTP 200，数据库状态 ok，业务版本仍为 `236ecd1`。

1. 用原 stop-tunnel.ps1 验证进程命令与启动时间后停止失效穿透，保留原 API/Worker。

4. 新地址 HTTPS ready 返回 200，原网站 Origin 的登录 CORS 预检返回 204，允许来源精确匹配。
5. 独立无头浏览器使用候选静态页面、实际公网 API，验证健康 200、产品配置 200、匿名 auth/me 401、空登录请求 DTO 校验 400；没有提交账号密码，且无页面 JavaScript 错误。

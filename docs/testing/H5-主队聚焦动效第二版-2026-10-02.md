# 主队聚焦动效第二版

用户要求：按钮图案默认更小，悬停变化更大；点击主队后使用多条线向中心聚拢，明显衬托队徽；拉开中心入口与两侧的距离。本轮只修改桌面 H5 导航，沿用上一版立即切换与顶栏固定表现。

## 修改文件

- `apps/mini-program/src/components/public-shell/index.tsx`：加入 H5 聚焦装饰；再次点击当前主队入口重播动画。
- `apps/mini-program/src/components/public-shell/index.scss`：队徽默认 40px，选中 1.16 倍，悬停 1.42 倍；桌面中心列从 76px 增至 132px。小桌面中心列为 112px、队徽为 38px。修正不等宽导航列下的指示条坐标。
- `apps/mini-program/src/components/public-shell/navigation-transition.h5.ts`：六条轮廓向中心收拢，同时逐渐绘制；三对轮廓间隔 35ms，每对运动 280ms，整个焦点形成过程为 350ms。重播先取消上一组动画，离开页面时清理；键盘与减少动态效果模式保持静态选中轮廓。
- `apps/mini-program/src/components/public-shell/navigation-transition.ts`：非 H5 重播空实现。
- `apps/mini-program/src/components/public-shell/team-nav-focus.h5.tsx`：六条 SVG 弧线，深绿主线、淡金外线、深绿底部线；无实体背景框。
- `apps/mini-program/src/components/public-shell/team-nav-focus.h5.scss`：桌面 H5 专用装饰样式和淡悬停预览；移动尺寸隐藏。
- `apps/mini-program/src/components/public-shell/team-nav-focus.tsx`：其他平台不渲染装饰。
- 本记录。

未纳入赛程、数据页、详情页等其他进行中任务文件。

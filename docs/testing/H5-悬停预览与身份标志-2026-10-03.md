# 桌面 H5 悬停预览与身份标志

用户最终要求保留球员三列数据、缩小预览高度，而不是改成一行统计。此轮基于 `75de7fe`，继续在 `codex/player-profile-dialog` 完成。未合并、推送或部署。

## 结果

- 预览保留封面、头像、姓名、球队/位置/号码、三列比赛数据和两按钮；缩小封面、头像、数据字号与垂直间距，移除预览中的「演示档案」标签。
- 号码显示为「10号」等明确文字，替代 #10。
- 姓名右上侧加入 19px 身份标志。认证球员为绿色盾牌，认证赛事工作人员为金色日历和小勾，认证学生为蓝色身份圆章和小勾。完整说明默认隐藏，鼠标悬停和键盘聚焦时展示。
- 认证标志可复用于不同人物。已接入桌面动态作者的既有 verificationLevel，以及球员预览的明确传入状态/本人会话认证状态。没有来源证明的球员使用灰色「球员档案」标志，不标为已认证；普通未认证账号使用灰色「普通用户」标志。
- `PersonHoverPreview` 作为可复用的预览身份区，比赛数据为可选内容；后续普通学生/工作人员预览不传 stats 即会缩短。本轮没有增加全站普通用户资料 API 或新的普通用户弹窗宿主。
- 数据页人物、球队链接移除下划线和整行悬停底色，仅保留轻微文字变色；键盘焦点轮廓仍保留。

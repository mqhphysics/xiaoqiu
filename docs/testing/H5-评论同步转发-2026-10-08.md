# 桌面 H5 评论同步转发

任务：[FEED-03](../tasks/FEED-03-H5-评论同步转发.md)。起点为 main `491cb53`；用户明确授权完成后直接集成 main。

## 本轮行为

- 表情右侧增加圆形勾选项“评论同步转发到动态”，默认不勾选，可鼠标或键盘切换，发送时禁用；关闭重开详情恢复未勾选状态。
- 勾选后，发送/回车发布评论，同时以评论正文发布一条引用原帖的社区动态；不附带标签、球队发布身份或图片。首页即时插入新动态，详情保留在当前评论区。
- 未勾选时继续只发评论；独立转发入口及其原发布框保留。
- 评论、同步动态、动态审计和通知在同一个 PostgreSQL 事务中提交。通知写入失败时，两份内容及审计一起回滚。
- 重复请求只生成一条评论及一条同步动态；同一评论提交编号切换同步选项返回 409。本轮并发测试发现 Prisma 嵌套 upsert 的唯一键冲突，改为 createMany/skipDuplicates 后读取；同时修正同一测试实测的并发评论点赞冲突。
- 复用已有 Post 引用与幂等字段，没有模型、迁移、公共契约、生成 Client、依赖或锁文件修改。共享评论 API 增加可选 boolean，旧客户端不传时行为保持。

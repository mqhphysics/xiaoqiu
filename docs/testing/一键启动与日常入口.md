# 一键启动（2026-10-01）

直接在主项目 `D:\MuDevSpace\xiaoqiu` 双击 `打开晓球网站.cmd`。

启动辅助程序位于 `scripts/desktop-entry/open-website.ps1`，按相对路径定位它所在的项目，不依赖旧目录、不依赖 Codex 工作树，也没有创建新的项目副本或目录联接。

它调用原来的 `scripts/start-local-demo.ps1`：尝试启动 Docker Desktop，等待 PostgreSQL，执行迁移，后台启动 API（3001）与 H5（3000），就绪后自动打开网站。普通启动不运行 Seed；已有健康服务复用。重复双击时会提示等待已有启动窗口。

Docker 自动启动失败时，手动打开 Docker Desktop，等引擎就绪，再双击启动文件。失败窗口保留错误。启动日志在 `private-data/runtime/launcher/`，API/H5 日志在 `private-data/runtime/`。Node.js、Docker Desktop、项目依赖需事先安装。

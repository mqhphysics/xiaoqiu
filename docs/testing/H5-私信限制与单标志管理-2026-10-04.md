# PLAYER-03 私信限制、单标志及输入修正

对应 [任务卡](../tasks/PLAYER-03-H5-私信限制与标志管理.md)。用户已明确仅 `PLATFORM_ADMIN` 可发送私信，并授权本人物任务并入 main。本轮仍在独立 `codex/player-profile-dialog` 工作树开发；2026-10-04 收到 Integrator 3 收齐成果的通知，交由该集成负责人统一处理 main、GitHub 和新环境验收，不与其同时修改日常服务。

## 已实现

- 服务端发送入口在任何消息事务前校验 `PLATFORM_ADMIN` 与 `PLATFORM` 范围；普通用户、队长、信息管理员、组织管理员和赛事管理员不能发送。会话与历史仍可查看；桌面输入区只读，点击提示「此功能暂未开放，敬请期待」。平台管理员可以正常输入。
- 每个人展示一个有效身份标志，默认按运营、赛事管理员、信息管理员、审核员、比赛官员、队长、球员/学生顺序选取。队长默认不再并列展示球员。足球线条与下方勾沿用前轮方案。
- 「我的 → 展示标志管理」支持自动选择或选择本人已有身份。选择按账号和组织持久化，不改变角色或权限；保存带版本冲突检查、幂等记录和审计。身份撤销后，公开资料与本人设置自动回退到仍有效的身份。
- 修复图片/纯文字动态姓名与标志的换行错位；桌面动态卡片移除重复私聊按钮。人物预览和详情中的私信入口继续保留。
- 私信、我的信息表单、反馈与选主队搜索移除文字输入焦点的绿色外框。反馈使用桌面原生输入，字号为 14px，补充说明使用单层文本区，取消按钮保留可见文字；球队搜索移除浏览器默认内框。
- 首页动态、动态详情和我的动态采用一致的空心/实心爱心：成功点赞后实心、取消后空心，与数量及 `aria-pressed` 状态同步。修正首页点赞数量继承 Taro 浅白色造成的不清楚显示。

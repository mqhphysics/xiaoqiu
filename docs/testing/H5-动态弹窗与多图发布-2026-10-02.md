# 桌面 H5 动态弹窗、多图与 GIF 验收

日期：2026-10-02。范围：用户指定的桌面动态浏览与发布功能，真实本地 API/PostgreSQL 往返。没有推送、合并或部署。

| Before                               | After                                    | Why                                  |
| ------------------------------------ | ---------------------------------------- | ------------------------------------ |
| 打开动态跳转详情页，图片单独调用预览 | 保留原页面的左右分栏详情弹窗             | 图片与评论同屏，关闭后继续浏览原位置 |
| 发布使用大框套输入框、文字式提示     | 620px 发布窗口、直接输入、图标工具栏     | 减少无效边框和空白，发布操作集中     |
| 单张静态照片与大移除按钮             | 最多九图、角标删除、GIF 动画保留         | 支持连续比赛照片和足球动图           |
| 回复平铺为同一级评论                 | 顶层评论下收纳回复，连续回复显示目标作者 | 保持紧凑且能辨认讨论关系             |

已满足 FEED-01 六项验收。详情支持缩略图、悬停上一张/下一张、滚轮缩放至 100–500%、按钮缩放、重置、双击缩放、放大拖动和方向键切换。发布和评论均有足球/黄豆表情按钮；支持光标位置插入、正文计数、失败保留草稿、重复点击保护及幂等重试。评论回复使用既有 parentCommentId 接口；界面默认显示两条回复，可以展开剩余回复。

素材：内置 16 个足球/助威表情和 24 个黄豆表情，来源为 [Twemoji v17.0.0](https://github.com/jdecked/twemoji/tree/v17.0.0)，图形许可 CC BY 4.0；14 个工具栏图标来自 [Tabler Icons v3.35.0](https://github.com/tabler/tabler-icons/tree/v3.35.0)，MIT。来源说明和完整许可证均入库。

## 边界与协调

公共文件变更建议：本轮无需修改 schema、contracts、生成 API Client、package.json 或锁文件，没有新增运行依赖。

媒体仍使用项目现有本地文件适配器。相册封面地址保持可读取图片，文件名同时记录相册内容哈希、数量和序号；每张图片的公开读取都验证所属组织、作者及封面动态仍为 PUBLISHED。JPEG/PNG/WebP/GIF 每张服务端输入最大 4 MiB，静态图片由前端压缩，GIF 总帧数与解码像素数设限；多图 data URL 总长最大 24,000,000 字符。生产对象存储、配额/生命周期和部署验证未做，需在生产媒体适配器接入时保留整组成员关系和访问规则。

本提交只包含本任务代码；共享首页与 app.tsx 中的其他在途图标、首页轮播、光标和导航工作保留在工作区，按行排除。集成负责人需要按现有流程审查本提交，并将前后端一起集成；普通提交不构成生产验收。

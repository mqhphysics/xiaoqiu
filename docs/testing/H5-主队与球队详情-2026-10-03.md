# 桌面 H5 主队与球队详情验收记录

本轮实现用户提供参考图中的两种界面：主队页保留球队/球员选择条；球队详情窗口顶部展示基本资料，两者共用三个内容选项。范围遵循 [TEAM-01](../tasks/TEAM-01-H5-主队与球队详情.md) 与根目录 AGENTS.md。

## 实现结果

- 主队标题旁使用小切换图标及悬停提示；球队选择窗口列出当前赛事全部球队，可按名称、简称和学院搜索。球队以 ID 区分，演示球队注明来源。
- 顶部保留主队、关注球队、关注球员。球队名和队徽打开档案，小圆按钮切换下方球队内容；查看关注球队不改变主队。可通过现有 API 管理球队/球员关注。
- 动态与赛程：沿用既有帖子、点赞、动态详情和发布组件；赛程来自完整赛事记录，并可筛选全部、即将进行和历史比赛。
- 球员与数据：教练、队长、按位置分组的公开阵容，出场/进球/助攻，以及比赛战绩、小组位置、淘汰赛进程。场均进球和失球由已读取的总数和场次计算。
- 资料与转会：显示已有成立年份、院系、编号、颜色、简介。未提供的荣誉、历史阵容、历史教练及人员变动明确显示暂无记录；未采集技术统计显示「—」。没有复制参考图中的人物、故事、荣誉或数字。
- 详情窗口与页面共用内容；窗口保留来源页面 URL，支持 Escape、焦点恢复、Tab 焦点约束及动态/发布窗口嵌套。独立球队地址保留原返回处理。
- 首页、赛程、数据榜单、我的、球员、比赛、球队目录及赛事详情的球队入口接入平台导航；名称使用柔和绿色悬停提示。主队导航徽章仍执行原导航功能。
- 主队页的首页读取、可用球队及球员搜索带当前赛事参数，使用后端已经支持的查询参数。未修改 API、数据库、公共契约或依赖。

## 未解决问题与集成协调

- 当前公开接口没有球队荣誉、故事节点、历史教练/阵容、人员变动或完整技术统计数据，本轮只展示明确空状态。若要填充参考图中的完整历史资料，需要由数据/API 负责人安排字段及来源。
- 球队的其他赛事记录受已有注册与公开范围控制；不存在该队档案时不能展示该赛事阵容。部分旧赛事的汇总接口仍不可用，界面已提供错误和恢复流程。
- 发布沿用现有后台权限与默认赛事规则；本轮仅透传所属球队，未更改发布业务契约。
- 公共文件及依赖变更建议：无。
- 本轮成果保存在 `codex/h5-team-dashboard`，主目录 3000 仍是集成目录已有版本。需要集成负责人按明确授权纳入本分支；共享文件中的其他任务修改须按行保留。没有推送、合并 main 或部署。
- 浏览器验收临时启动的 API 在任务收尾时关闭；数据库和原 3000 服务保持原状态。

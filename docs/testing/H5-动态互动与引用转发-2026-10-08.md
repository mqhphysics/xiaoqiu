# 桌面 H5 动态互动与引用转发验收

任务：[FEED-02](../tasks/FEED-02-H5-互动与引用转发.md)。基线 `7a6a777`，任务分支 `codex/h5-feed-interactions`。用户在本聊天明确授权修改这次功能必需的 Prisma 模型及迁移。

## 已实现并验证

- 评论输入去掉绿色聚焦外框；Enter 发送，Shift+Enter 换行。中文组字回车及 keyCode 229 不触发发送，重复提交继续使用原幂等键。
- 详情及评论菜单移除重复私信入口，通过人物资料进入私信。
- 帖子详情持续显示赞数、点赞状态；评论增加点赞及数量，重新打开时从真实 API 恢复。
- 仅帖子可收藏，收藏/取消使用真实数据库，同一用户重复请求不新增重复记录。评论没有收藏按钮或收藏接口。
- 投诉收进三个点下方的浮层，打开菜单不改变正文/评论高度。点击外部关闭，Escape 只关当前菜单。
- 本人帖子/评论只有编辑和删除；其他人内容可投诉。服务端校验作者及组织，并拒绝投诉本人内容。编辑使用版本比较，过期编辑/删除返回 409；删除采用隐藏并保留审计与回复，重复删除不新增审计。
- 转发打开发布框，引用卡片显示原作者、最多三行正文及最多两张配图；支持附带自己的文字、图片和标签。首页新增卡片、详情正文编辑及删除同步使用现有互动存储。
- 原动态不可见时，引用返回空内容并显示“原动态已删除或不可见”，不继续展示旧正文/媒体。
- 发布框移除“全校可见”；当前主队优先出现在一行标签建议中。球队标签沿用组织公开目录，不要求赛事报名，名称由服务端解析；球员标签仍要求原有赛事公开档案。标签不会授予球队官方发布权限。
- 桌面卡片使用自身点赞请求时，不再因缺少外部 onLike 回调而禁用；实测鼠标悬停的按钮可用、没有 not-allowed 光标。

## 运行与交接

父 Sites 发布应运行根 `build:sites`（或 `node scripts/build-sites-bundle.mjs`），使用同一非敏感 API URL 和组织 UUID，部署整个 `apps/mini-program/dist`，保留其中 `/admin/`，不要将它重写成 H5 首页。CSP 应允许本站资源和精确 API origin；上传/播放媒体需要保留已有 `blob:`/`data:` 图片策略。

API 生产启用新媒体前配置绝对持久 `MEDIA_ASSETS_DIRECTORY`；版本化程序产物复用同一媒体目录，数据库与媒体应一起备份。公开专用库不运行 full seed，不更换私有管理员密码，不停止原手工 Worker 或日常入口。旧 API 编译产物保留，新增迁移是加法变更，程序回退与数据库副本恢复分别验证。

最新分支的公开 Sites 发布、已登录整站浏览器和运行时同步结果由后续非敏感交接记录确认。本轮未做实体手机、Safari、微信真机/本地 weapp 构建、负载或长期稳定性验收。备份恢复在隔离副本执行，没有对公开库做破坏性恢复。

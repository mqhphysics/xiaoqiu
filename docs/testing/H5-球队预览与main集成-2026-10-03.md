## 行为

顶部主队、关注球队和关注球员卡均为下方内容选择器。名称、队徽、头像或卡片空白处点击都在当前页面切换，不导航，不打开详情弹窗。删除前轮对卡片文字/空白的两种操作划分。

球员内容复用 main 的 `PlayerProfile` 和双选项：动态与数据、比赛与资料。球员本人发布的动态以及标签关联动态按 ID 去重后同时保留；内嵌组件及弹窗继续支持带球员标签的发布。球员页面/弹窗共存时使用唯一的选项 ID。

其他位置复用 main 的球员、人物预览及资料弹窗。新增球队预览：悬停延迟 320ms、离开延迟 220ms，移入预览框保持显示；队徽、院系、口号、球员人数和战绩均来自公开 API。点击进入已有球队详情，保留来源页面 URL。滚动/缩放/其他实体预览会关闭悬停卡，失败可重试。

保留 main 的私信抽屉、角色与认证标志、公开人物 API，以及前轮帖子标签和原图片发布。合并公开球员查询时同时保留账号本人帖子与球员标签帖子，避免任何一方被另一方覆盖。公共壳层同时挂载球队、人物和消息宿主；键盘焦点沿用 main 支持人物与私信共存的处理。

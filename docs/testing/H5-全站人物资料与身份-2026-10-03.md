# H5 全站人物资料与身份

对应 [PLAYER-02](../tasks/PLAYER-02-H5-全站人物与main集成.md)。用户已授权将本任务分支 `codex/player-profile-dialog` 合入 main；本记录先保存实现与合并前证据，日常入口验证在合并后补记。未授权 push 或部署。

## 实现

- 认证球员使用简洁线条足球与下方小勾。根据有效角色分别显示认证队长、信息管理员、网站运营、赛事管理员等标志；多个身份可以同时展示。MATCH_REPORTER 显示信息管理员，PLATFORM_ADMIN/ORGANIZATION_ADMIN 显示网站运营，TEAM_CAPTAIN 显示认证队长。
- 新增 `GET /api/public/people/:userId`，以稳定账号 ID 查询公开身份、简介、当前赛事公开动态，以及通过数据库唯一绑定关系取得的公开球员资料。球员、动态作者及评论响应补充有效角色和账号关联；动态补充 tournamentId，人物入口保留赛事上下文。
- 内容人物入口通过 person-trigger 统一接线：首页动态作者头像/姓名与搜索结果、动态详情及楼层/回复作者、比赛评分与事件/阵容、球队/主队名单与队长工作台、我的动态/通知、私信联系人/对话头像及姓名。点击人物不会再同时打开父级动态卡片。
- 非球员资料使用一个「动态与资料」区，包含公开动态、昵称、身份、简介；悬停预览省略比赛统计。已关联且具有当前赛事公开球员资料的账号使用既有双选项球员弹窗，动态及私信目标均来自实际账号绑定。
- 人物弹窗可从动态详情上方打开；关闭后回到原动态，打开动态时关闭人物层。人物预览在消息窗口之上，人物资料与右侧消息可并存。
- 原账号头像菜单、换头像控件和排阵编辑控件保留原操作。只有文本姓名、没有账号/球员 ID 的教练等说明不凭同名绑定档案；源数据缺少身份关系的情况保留文本。
